MentorLink 🎓

What is MentorLink?

MentorLink is a simple platform that connects students with mentors. Students can find mentors based on their skills, book sessions, send messages, and get feedback. Mentors can manage requests and help students grow.

Why MentorLink?

Learning works best with guidance, but finding the right mentor is hard. MentorLink makes it easy — search for a mentor you like and start learning.

Key Features

- Find Mentors — Browse by skills, experience, and hourly rates
- Book Sessions — Schedule mentoring sessions easily
- Real-time Chat — Message your mentor directly
- Feedback System — Give and receive ratings and reviews
- Secure Authentication — Safe login with password reset via OTP
- Google Sign-in — Quick login with Google
- Role-based Access — Different features for students and mentors

Tech Stack

Backend:
- Node.js
- Express.js
- MongoDB

Frontend:
- EJS
- HTML
- CSS
- JavaScript

Security:
- JWT
- bcrypt

Email:
- Gmail SMTP for OTP delivery

Storage:
- Multer (local)
- Cloudinary (cloud)

Getting Started

1. Clone the project
2. Install dependencies:
   npm install

3. Set up .env with:
- MongoDB URI
- JWT secret
- Gmail credentials

4. Start the server:
   npm start

5. Open:
   http://localhost:3000

How It Works

1. Sign Up — Create an account as a student or mentor
2. Find Mentors — Browse mentors by skills
3. Request or Book — Send a mentor request or book a session
4. Connect — Chat and schedule sessions
5. Learn & Grow — Get guidance and feedback
